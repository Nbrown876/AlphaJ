## 💻 Run Locally

### Prerequisites

* Python 3.8+

* pip

### Steps

1. Clone the repository:

```bash
git clone https://github.com/Nbrown876/AlphaJ.git
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

1. Create a `.env` file in the root directory and add your OpenAI API key:

```
OPENAI_API_KEY=your_api_key_here
```

1. Run the application:

```bash
python app.py
```

1. Open your browser and go to:

```
http://localhost:5000
```

## 📌 What It Does

Alpha J is a general-purpose, high-level, imperative programming language. It supports:

* Variable declaration and assignment

* Arithmetic with correct operator precedence (PEMDAS)

* Conditional statements (`if` / `fallback`)

* Loops (`cycle`)

* Exception handling (`try` / `catch`)

* String and numeric output (`broadcast`)

* LLM-assisted code analysis via OpenAI
